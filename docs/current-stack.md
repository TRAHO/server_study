# 현재 운영 서버 스택 (이전 기준)

기존에 쓰고 있는 서버 환경이다. 새 iwinv 서버는 이 조합과 **호환**되게 맞추되, OS만은 그대로 복제하지 않는다.

## 현재 스택

| 항목 | 버전 | 비고 |
|------|------|------|
| OS | CentOS 7.x | **EOL** — 신규 서버에 설치 금지 |
| PHP | 7.3.33 | 요구: 7.3 이상 |
| DB | MariaDB 10.0.21 | 요구: 10 이상 |
| 웹서버 | Apache 2.4.6 | 요구: 2.4 이상 |

## 신규 iwinv 서버 목표 스택

| 항목 | 권장 | 이유 |
|------|------|------|
| OS | **Ubuntu 22.04 LTS** (또는 24.04) | CentOS 7 대체, 제어판·보안 업데이트 용이 |
| 웹서버 | **Apache 2.4.x** | 현재와 동일 계열 → `.htaccess`·가상호스트 이전 수월 |
| DB | **MariaDB 10.6+** (또는 10.11) | 요구사항(10+) 충족, 10.0보다 안전 |
| PHP | **7.4 또는 8.1/8.2** (사이트별 선택) | 7.3도 EOL. 제어판에서 다중 PHP 설치 후 사이트마다 지정 |

> 레거시 사이트만 PHP 7.4, 신규·워드프레스는 8.x처럼 **사이트별 PHP 버전**을 다르게 두는 방식을 권장.

## 이전 시 체크

- [ ] 소스·DB 덤프 (문자셋 `utf8` / `utf8mb4` 확인)
- [ ] Apache vhost / `.htaccess` 동작 확인
- [ ] PHP 확장 모듈 (mysqli, gd, mbstring, zip, curl 등) 맞추기
- [ ] cron, 메일 발송, 파일 업로드 경로 권한
- [ ] 가능하면 PHP 7.3 → 7.4/8.x 로 올려 보고 에러 로그 확인
