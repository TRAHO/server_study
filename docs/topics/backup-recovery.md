## 무엇이 다른가

| | 카페24 리셀러 | iwinv 자체 |
|--|---------------|------------|
| 백업 | 상품·정책 범위의 플랫폼 백업에 의존하는 부분 큼 | **서버 밖 백업을 직접** 설계·운영 |
| 위험 | 정책·신청 절차에 묶일 수 있음 | “백업은 있는데 복구가 안 되는” 상태를 스스로 막아야 함 |

서버 디스크만 복사해 두면, 서버·디스크가 같이 날아가는 장애에 취약하다.

## 자체 운영 시 대응 방향

1. 제어판 백업 + **외부** 저장소(Google Drive / S3 등) 연동
2. 스케줄 예: 매일 새벽 — 전 계정 소스 + DB
3. 보관 주기·용량 정책 정하기
4. **복구 테스트**를 주기적으로 수행 (파일 1사이트 + DB 1회라도)
5. 백업 실패 알림 확인을 운영 루틴에 넣기
