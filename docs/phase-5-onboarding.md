# Phase 5. 고객사 입주 및 관리

## 목표

제작이 끝난 고객 사이트를 서버에 올리고, SSL·모니터링·청구까지 루틴화한다.

## 5-1. 독립 계정 생성

1. 제어판 → **Add Site** / **Create Subscription**
2. 고객 도메인 입력 (예: `client.com`)
3. 디스크 할당 (예: 5GB)

### 고객별 기록 템플릿

| 항목 | 값 |
|------|-----|
| 고객명 | |
| 도메인 | |
| 할당 용량 | |
| 계정/FTP | |
| DB명 | |
| 입주일 | |

## 5-2. 소스·DB 이전

1. 파일 관리자 또는 FTP로 소스 업로드
2. DB 생성 후 덤프 임포트
3. 설정 파일의 DB 접속 정보·URL 수정 (CMS별)

```bash
# DB 임포트 예시 (서버에서)
mysql -u유저 -p DB이름 < dump.sql
```

## 5-3. SSL

1. 제어판 Let's Encrypt 메뉴
2. 고객 도메인에 인증서 발급
3. 자동 갱신 여부 확인

DNS가 서버를 가리킨 뒤에야 발급이 된다. (네임서버 변경 전파 대기)

## 5-4. 모니터링·청구

- 대시보드에서 고객별 CPU/메모리 사용량 주기 점검
- 계약 주기에 맞춰 유지보수·호스팅 비용 청구

### 점검 루틴 예시

| 주기 | 할 일 |
|------|--------|
| 주 1회 | 리소스·디스크 여유 확인 |
| 월 1회 | 백업 성공 여부·복구 가능성 확인 |
| 계약일 | 청구서 발행 |
