# Phase 4. 백업 및 네임서버 세팅

## 목표

고객 입주 **전**에 외부 백업과 자체 네임서버를 끝낸다.  
장애 시 빠르게 복구할 수 있는 안전장치가 목적이다.

## 4-1. 외부(3차) 백업

1. 제어판 백업 메뉴 이동
2. Google Drive 또는 AWS S3 API 연동
3. 스케줄 권장:
   - 시각: **매일 새벽 3시**
   - 대상: 전 계정 소스 + DB
   - 동작: 압축 후 외부 스토리지 업로드

### 기록

| 항목 | 값 |
|------|-----|
| 백업 대상 | Google Drive / S3 / 기타 |
| Cron/스케줄 | |
| 보관 기간 | |
| 복구 테스트 일자 | |

> 백업은 “돌려본 적 있는” 상태여야 한다. 입주 전에 1회 복구 테스트 권장.

## 4-2. 자체 네임서버(DNS)

마스터 도메인 관리 페이지에서 NS용 호스트를 등록한다.

```
ns1.내에이전시.com  →  스마일서브 서버 IP
ns2.내에이전시.com  →  스마일서브 서버 IP
```

고객 안내 문구 예시:

> 도메인 네임서버를 아래처럼 변경해 주세요.  
> `ns1.내에이전시.com` / `ns2.내에이전시.com`
